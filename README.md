# National Vital Statistics – DANE

This repository contains R scripts for processing and consolidating Colombia's vital statistics data: deaths, maternal deaths, births, and population projections, published by DANE. The scripts prepare the raw yearly microdata files for analysis, enabling demographic and public health trend studies at the national and departmental level.

Data source

All input files come from DANE's official releases:

- Estadísticas Vitales (deaths, maternal deaths, and births), by year
- Proyecciones de Población ("Formato ancho", 2018–2023)
